Installer sur Ordinateur & Android

Installation directe prête !
Votre navigateur permet d'installer l'application en un clic sans store.
💻 Sur Ordinateur (Windows / Mac / Linux)
  1. Ouvrez ce fichier via un serveur local (ex : npx serve ou VS Code Live Server) ou hébergez-le (GitHub Pages / Netlify).
  2. Dans Chrome / Edge, cliquez sur l'icône Installer l'application (⊕) à droite de la barre d'adresse.
  3. L'application apparaît dans votre menu Démarrer / Applications comme un logiciel natif hors-ligne.
📱 Sur Android (App & APK)
  1. Installation directe (PWA) : Ouvrez l'URL sur Chrome Android → Menu ⋮ → « Ajouter à l'écran d'accueil / Installer l'application ».
  2. Générer un fichier .APK : Téléchargez le pack ci-dessous et importez-le dans PWABuilder.com ou Capacitor pour compiler un APK signé.
